## Included in this release

- Reopening the editor now resumes each tab's actual AI conversation, not just the workspace layout
- Terminal scrollback is persisted (encrypted) and replayed above a "restored from previous session" divider
- Claude Code, OpenAI Codex CLI, OpenCode, and Google Antigravity CLI resume through their native session mechanisms
- GitHub Copilot CLI, Aider, and Mistral Vibe resume is enabled automatically when the installed version supports the required flags
- Agents that announce their session ids in output are picked up automatically, so resume also covers sessions GDAgent did not name itself
- New Resume Conversations setting: Always (default), Ask (per-tab "Resume Conversation / Start Fresh" choice), or Never
- New Persist Terminal Scrollback setting with a configurable per-tab size limit
- Tabs show Resumed/Fresh badges after launch; the tooltip explains why a conversation could not be resumed
- Restarting a crashed agent reattaches the same conversation; resume attempts that fail fall back to a fresh conversation automatically
- Expired or deleted conversations are detected before launch, so a stale handle can never wedge a terminal
- Added Grok Build (xAI) as a supported agent, with auto-install, bundled Godot MCP config in the project's `.grok/config.toml`, and session resume by session id
- Added Command Code (Langbase) as a supported agent, with npm auto-install, bundled Godot MCP config in the shared `.mcp.json`, and named-session resume enabled once the installed version supports the required flags
- New Agents tab in Settings: register your own agent CLI with a name and a command, and it opens in a tab like any built-in agent
- Custom agents are launch-only by design — GDAgent only knows the command you entered, so they are never probed for installation and get no install flow, no bundled Godot MCP config, and no conversation resume
- The agent picker now refreshes when custom agents are added or removed
